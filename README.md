# Alrobe International — Rebuild (Caribbean Bold)

Elegant stylish app for parts sale, car sale, car warehouse, logistics, new + used imports.

## Stack
- `client/` React + Vite + Tailwind v4 + React Router + Lucide
- `server/` Node + Express JSON API (no DB needed for v1)

## Run
```powershell
# Start API :5000 and web :5173 together
npm run dev

# Or run separately
npm run dev:server
npm run dev:client
```

## Features
- Parts shop: search, brand/category filters, VIN decode, cart → quote order
- Cars: New/Used filter, detail pages, test-drive lead
- Imports: CIF + CC + age → duty/GCT/landed calculator, quote saved
- Logistics + Warehouse: service pages from original site content
- Track: order/cargo timeline UI
- Admin: orders + quotes dashboard, revenue
- Contact: lead form
